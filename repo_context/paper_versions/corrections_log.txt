EARLIER STATISTICAL REFRAMING (Aimee's notes)
------------------------------------------------------------------------------
1. Ambiguity gradient r=0.9565:
   Removed inflated "p=3.20e-54" (computed over interpolated grid, not
   independent samples). Replaced with permutation test p<0.001 (n=5000
   shuffles). Added explicit caveat that r is computed over 100 interpolated
   grid points and should not be treated as an independent-sample p-value.

2. Void/Belt density similarity:
   Added caveat that density-shape similarity does not reach conventional
   significance under permutation testing (Wasserstein p=0.46). The claim
   is now explicitly descriptive — shared organisational logic, not matched
   compression.

3. 48D RDM (3-point Pearson):
   Reframed as "directional evidence only" with wide bootstrap CI
   [-0.9967, +0.6994]. Promoted the 11D fine-tuned bootstrap CI
   [-0.9899, -0.1178] (fully negative) as stronger inferential support.

4. Statistical hierarchy paragraph added to Discussion:
   Ranks evidence from strongest (margin-uncertainty coupling, AUC=0.81,
   permutation p<0.001) down to descriptive only (48D RDM, Void/Belt density).
